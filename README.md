# MERAQ FINANCE — installierbare Web-App

Dieses Repository enthält ausschließlich das **fertig gebaute Ergebnis** der App,
damit GitHub Pages sie ausliefern kann.

**Live:** https://marcel-fe.github.io/meraq/

Der Quellcode liegt privat in einem separaten Repository. Hier stehen nur die
kompilierten Dateien — keine Dokumente, keine Spezifikation, keine persönlichen
Daten.

## Was die App ist

Ein privates Finanz-Betriebssystem mit dem Berater **Mero**: Vermögensübersicht,
Cashflow, Verträge mit Fristen, Ziele und eine nachvollziehbare Einschätzung der
eigenen Lage.

## Datenschutz

Die App hat keinen Server und keine Datenbank. Alle eingegebenen Zahlen bleiben
im Browserspeicher des jeweiligen Geräts und werden niemals übertragen. Wer diese
Seite öffnet, sieht ausschließlich einen Demo-Datensatz mit erfundenen Werten.
